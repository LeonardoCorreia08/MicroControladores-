#  Projetos de Microcontroladores

Bem-vindo ao meu repositório da disciplina de Microcontroladores! Este espaço foi projetado para organizar todos os códigos, exercícios e atividades práticas desenvolvidos ao longo do curso. O objetivo é manter tudo limpo, fácil de entender e pronto para ser testado.

##  Como este repositório está organizado?

Para evitar confusão e manter o código organizado, os arquivos estão divididos nas seguintes pastas:

*   📁 **`atividades/`**: Aqui ficam os códigos desenvolvidos durante as aulas e as tarefas principais solicitadas pelo professor. Cada atividade terá seu próprio arquivo.
*   📁 **`exercicios/`**: Pasta dedicada à resolução de pequenas listas, desafios extras e testes curtos para fixar os conceitos aprendidos.
*   📁 **`bitdoglab/`**: Projetos e experimentos específicos voltados para a plataforma/placa **BitDogLab**. É aqui que a interação com os componentes dessa placa específica acontece.

##  Como utilizar

1. **Navegue pelas pastas:** Abra a pasta correspondente ao que você deseja estudar ou modificar.
2. **Use o Template:** Sempre que for criar uma nova atividade em qualquer uma das pastas, copie o arquivo `template_base.py` para a pasta desejada. Ele já tem a estrutura pronta (Setup e Loop) com instruções em comentários.
3. **Execute no Microcontrolador:** Abra o arquivo escolhido na sua IDE (como o Thonny, muito usado para MicroPython) e envie para a sua placa.
